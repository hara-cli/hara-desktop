# 1.0.4 local candidate learnings

## [LRN-20261020-PANEL-GRID] regression / frontend

**Status**: resolved in local candidate, not released

The Workspace browser introduced in be751266 used an absolute-positioned ≤1100px fallback, so the
default extension covered chat even though its copy claimed to be a right panel. Its child-local
maximize state and stored width never controlled the parent grid. Keep layout/mode ownership in the
Workspace, retain chat DOM, and cap the right column against readable chat space. Prove non-overlap
using actual bounding boxes, including narrow windows and saved 72% width, not CSS source alone.
Shared labels are passed from the parent: importing the same runtime copy helper in the lazy child
made Rollup merge its entry into an internal chunk and broke the existing exact module-closure gate.
Passing typed copy preserves the original lazy entry and all assertions, without altering the gate.

## [LRN-20261020-SIGNING-FILE] security / infra

**Status**: synthetic tests passed; real signed candidate still pending

Jeff explicitly restored the existing updater-file source for formal signing. Do not infer this from
an earlier key-file exception: wire the formal caller and test it. Use read-only/no-follow/nonblock,
same-user regular 0600 file, no hardlinks, bounded bytes and pre/post read metadata. Resolve a HOME
system alias first (macOS /var → /private/var); reject a symlink at .tauri or the key, rather than
mistaking the system temp-root alias for an unsafe .tauri symlink. Never put secrets in argv/files/logs.
Buffer child output and redact combined chunks before delivering it, including failure output.

## [ERR-20261020-LOCAL-PROBE-PATHS] task checks

**Status**: resolved

Initial diagnostic commands guessed two nonexistent workspace CSS/theme filenames and mixed root ops
paths with a Desktop cwd. Use rg --files and keep root-level ops calls explicitly in the root. Also,
capture a gate's exit code before tailing its log; successful tail must not hide a failed test process.
Raw failed test/visual receipts are retained, not overwritten by subsequent successful runs.

Browser opening changes line wrapping, so its anchored scrollTop may legitimately adjust. For
maximize/restore compare against the settled docked reading position, retain the exact chat DOM and
session/draft, and ensure view actions perform no model/RPC sends. The first fixed-layout browser
test incorrectly compared a pre-reflow hardcoded offset; its failure evidence remains available.
