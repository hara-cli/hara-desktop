# Hara Desktop 1.1.0

- 全新工作空间布局，让 Hara、同事、私聊和任务更易找到。浅色和深色主题铺满窗口，搭配牛血红强调色。
- 在本机创建个人频道，添加当前工作空间的同事，无需登录云端，也没有频道成员人数配额。每条消息可让全部或部分同事回复，也可只保存为笔记。频道记录保存在本机当前工作空间。
- 按姓名或角色搜索频道成员和回复对象，搜索时保留已选同事，并显示回复人数。较窄聊天区域的操作更紧凑，较矮窗口中仍可方便地保存更改。
- 本地网页预览在聊天右侧展开，可放大、还原或关闭面板，聊天和草稿持续保留。
- 界面语言默认跟随系统，可在设置中切换简体中文、繁体中文或英语。连续操作合并为一行，可展开查看详情。
- 修复开关背后的方形底色，浅色、深色以及悬停、键盘聚焦、禁用状态均保持胶囊外形。
- 修复设置总览的英文连接数量文案：一个有效连接显示“1 connection”，零个或多个连接使用复数。

本版邀请他人为占位，不承诺上线时间。个人频道可与当前工作空间的本机 同事一起使用。
